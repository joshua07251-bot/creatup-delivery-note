작업을 마치고 고객에게 결과물과 함께 보내는 공식 문서입니다.

이 기기의 브라우저에 자동 저장

납품 항목

파일·링크·문서처럼 실제로 전달하는 것을 하나씩 적어주세요.

비밀번호는 적지 마세요. 계정·인증 정보는 이 문서가 아닌 별도의 안전한 방법으로 전달하세요.

확인 방법과 조건

예시 조건은 참고용입니다. 실제 견적서·계약서 내용과 맞춰 수정하세요.

저장과 출력

  1. 인쇄 · PDF 저장 — 인쇄 창에서 대상을 ‘PDF로 저장’으로 고르면 A4 PDF가 만들어집니다. 배경 그래픽 옵션을 켜면 색이 그대로 나옵니다.
  2. 문서 HTML 저장 — 편집 패널 없는 문서 파일입니다. 열어서 상단 버튼으로 인쇄할 수 있습니다.
  3. 편집본 백업 — 다시 수정하기 위한 JSON 파일입니다.
  4. 다음 납품 새로 시작 — 보내는 사람 정보와 기본 조건은 그대로 두고 고객·항목만 비웁니다.
문서의 수정·환불·권리 문구는 법률 검토를 거친 약관이 아닙니다. 실제 계약 조건이 우선하며, 중요한 거래는 계약서로 정리하세요. 입력 내용은 서버로 전송되지 않습니다.
A4 미리보기 · 실제 출력은 인쇄 창에서 확인하세요
